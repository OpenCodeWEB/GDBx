Global Decentralized DataBase Sync — one address, every technology

যেমন .onion Tor-কে বোঝায়, .GDBx বোঝায় Global Decentralized Database

GDBx একটি ওপেনসোর্স, সার্ভারলেস, ডিসেন্ট্রালাইজড ডেটাবেস সিঙ্ক প্রোটোকল। একটি checksummed address দিয়ে Tor v3, I2P, Nostr, WebRTC, IPFS ও GunDB mesh — সব প্রযুক্তি একসাথে রাউটেবল।

🔐 Checksummed Address

BLAKE3 checksum + Base32 (RFC 4648) — 58-char, typo/forgery-proof, collision-resistant। Version ও Network byte সহ।

🛰️ Multi-Transport

এক address → WebRTC (<20ms), Nostr (<150ms), Tor v3, I2P, IPFS — স্বয়ংক্রিয় selection + fallback।

🧬 CRDT Sync

GunDB mesh-ভিত্তিক flat-primitives JSON, conflict-free merge, delta sync, presence heartbeat।

⚡ Serverless

Cloudflare Workers + Durable Objects + Pages — local-first, সেন্ট্রাল সার্ভার নেই।
